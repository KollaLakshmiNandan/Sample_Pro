What is Jenkins?

Jenkins is an open-source automation server used to build, test, and deploy applications automatically.

CI/CD:
Continuous Integration & Continuous Deployment help automate software delivery.

Why Jenkins is Used

Git Integration

Automatically pulls code from GitHub.

Testing

Runs automated tests for applications.

Deployment

Deploys applications automatically.

Jenkins Pipeline

pipeline {

    agent any

    stages {

        stage('Build') {
            steps {
                echo 'Building application'
            }
        }

        stage('Test') {
            steps {
                echo 'Running tests'
            }
        }

        stage('Deploy') {
            steps {
                echo 'Deploying application'
            }
        }

    }

}

Maven in Jenkins

Maven is a Java build tool used to compile, package, and test Java applications. 

mvn clean package
clean → Removes old build files
package → Creates JAR/WAR file

Popular Jenkins Plugins

Plugin Purpose
Git Plugin Connect Jenkins with GitHub
Maven Plugin Build Java applications
Docker Plugin Docker integration
Kubernetes Plugin K8s deployment support
Slack Plugin Notifications & alerts

Jenkins Workflow

Developer Pushes Code → Jenkins Detects Change → Build Starts → Tests Run → Application Deploys → Notifications Sent
