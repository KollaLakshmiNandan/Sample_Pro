Jenkins Basics

A beginner-friendly guide to Jenkins, CI/CD, pipelines, builds, plugins, and Maven

What is Jenkins?

Jenkins is an automation tool mainly used for CI/CD.

CI — Continuous Integration

Developers push code regularly, and Jenkins automatically builds and tests it.

CD — Continuous Delivery / Deployment

Jenkins automatically prepares or deploys the application to servers.

Why Jenkins is Used

Jenkins helps teams automate tasks like:

  1. Pulling code from GitHub or GitLab
  2. Building the application
  3. Running tests
  4. Creating build files
  5. Deploying the application
  6. Sending success or failure notifications

Simple Real-Time Scenario

Imagine a Java developer writes code and pushes it to GitHub.

Without Jenkins:

Developer pushes code → manually download code → manually run Maven → manually test → manually deploy

With Jenkins:

Developer pushes code → Jenkins automatically starts → pulls code → builds using Maven → runs tests → deploys

So Jenkins reduces manual work and saves time.

Important Jenkins Terms

1. Job / Project

A Jenkins job is a task created in Jenkins.

Build Java Application

2. Build

A build is one execution or run of a Jenkins job.

Build #1
Build #2
Build #3

3. Pipeline

A pipeline is a series of steps used to automate the software delivery process.

Code → Build → Test → Deploy

4. Jenkinsfile

A Jenkinsfile contains pipeline instructions.

5. Stage

A stage is one major section in a pipeline.

Build stage
Test stage
Deploy stage

6. Step

A step is a command inside a stage.

echo 'Building the application'
sh 'mvn clean package'

Simple Jenkinsfile Example

pipeline {
    agent any

    stages {
        stage('Build') {
            steps {
                echo 'Building the application...'
            }
        }

        stage('Test') {
            steps {
                echo 'Running tests...'
            }
        }

        stage('Deploy') {
            steps {
                echo 'Deploying application...'
            }
        }
    }
}

Jenkins Pipeline Example for Java Maven Project

pipeline {
    agent any

    stages {
        stage('Checkout Code') {
            steps {
                git 'https://github.com/example/my-java-app.git'
            }
        }

        stage('Build') {
            steps {
                sh 'mvn clean package'
            }
        }

        stage('Test') {
            steps {
                sh 'mvn test'
            }
        }

        stage('Deploy') {
            steps {
                echo 'Deploying application to server'
            }
        }
    }
}

What is Maven in Jenkins?

Maven is a build tool for Java projects.

It helps to:

  • Compile code
  • Download dependencies
  • Run tests
  • Create JAR or WAR files

Common Maven command:

mvn clean package

clean → removes old build files

package → creates a new JAR or WAR file

What are Jenkins Plugins?

Plugins are add-ons that give Jenkins extra features.

Plugin Use
Git Plugin Connect Jenkins with GitHub or GitLab
Maven Plugin Build Java Maven projects
Docker Plugin Work with Docker
Kubernetes Plugin Deploy using Kubernetes
Slack Plugin Send build notifications
SonarQube Plugin Code quality scanning

Jenkins Basic Workflow

Developer writes code → Pushes code to GitHub → Jenkins detects change → Pulls latest code → Builds application → Runs tests → Deploys application → Team gets result

Common Jenkins Commands in Pipeline

echo 'message'

Prints a message.

sh 'ls'

Runs a Linux command.

sh 'mvn clean package'

Builds a Java Maven project.

git 'repo-url'

Pulls code from a Git repository.

In Simple Words

Jenkins is like an automatic worker.

When a developer updates code, Jenkins automatically takes the latest code, builds it, tests it, and deploys it.

So Jenkins saves time, reduces mistakes, and makes software delivery faster.
