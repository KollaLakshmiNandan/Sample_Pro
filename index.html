Linux Commands and Their Functions

Introduction to Linux

Linux is an open-source operating system widely used in:

  • DevOps
  • Cloud Computing
  • Networking
  • Cybersecurity
  • Servers
  • Software Development

Popular Linux Distributions

  • Ubuntu
  • CentOS
  • Red Hat Enterprise Linux (RHEL)
  • Debian
  • Fedora
  • Kali Linux

Linux Command Syntax

command [options] [arguments]

Example:

ls -l /home
  • ls → Command
  • -l → Option
  • /home → Argument

1. Navigation Commands

Command Function
pwd Show present working directory
ls List files and directories
ls -l Show detailed file information
ls -a Show hidden files
cd directory Change directory
cd .. Move to previous directory
cd ~ Go to home directory
tree Display folder structure 
pwd
ls -la
cd /var/log

2. File and Directory Commands

Command Function
touch file.txt Create empty file
mkdir folder Create new directory
mkdir -p a/b/c Create nested directories
cp source destination Copy files
mv old new Move or rename files
rm file Remove file
rm -r folder Remove directory recursively
find Search files and directories 
touch notes.txt
mkdir projects
cp notes.txt backup.txt
mv backup.txt old.txt

3. Networking Commands

Command Function
ping Test network connectivity
ip a Show IP addresses
curl Transfer data from URLs
wget Download files from internet
ssh Remote server login
scp Securely copy files 
ping google.com
ip a
ssh user@server

4. Process Management Commands

Command Function
ps Show running processes
top Real-time system monitoring
kill PID Stop process
jobs Show background jobs 
ps aux
kill 1234
top

5. Pipe and Redirection Operators

Symbol Function
> Redirect output
>> Append output
| Pipe output
< Redirect input 
ls > files.txt
cat log.txt | grep error

Summary

Linux is one of the most important operating systems in modern IT infrastructure. Learning Linux commands helps in:

  • System Administration
  • DevOps Engineering
  • Cloud Engineering
  • Cybersecurity
  • Networking
  • Software Development

Mastering Linux commands improves troubleshooting, automation, and server management skills.
