# 🚀 Sample_Pro

## 📌 Project Overview

Sample_Pro is a modern DevOps & Cloud learning project built using HTML, CSS, and UI/UX concepts.

This project contains beautifully designed learning pages for:

- DevOps
- Linux
- Git & GitHub
- Docker
- Kubernetes
- AWS Cloud

The project focuses on learning DevOps concepts while also practicing:

- Frontend UI Design
- Responsive Web Design
- Animations
- Git & GitHub Workflow
- Documentation Writing
