# Sample_Pro

## Project Overview
This project contains basic DevOps concepts created using HTML.  
The purpose of this project is to learn and practice DevOps topics and GitHub workflow.

- Git and GitHub Commands
- CI/CD Concepts

- AWS Services

  - VPC
  - RDS
- Infrastructure as Code (IaC)

  - Grafana
  - Nagios
