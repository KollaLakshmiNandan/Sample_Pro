What is Ansible?

Ansible is an open-source automation tool used for configuration management, application deployment, infrastructure automation, and server provisioning.

Key Benefit:
Ansible is agentless, simple to learn, and uses SSH for communication.

Why Ansible?

Automation

Automate repetitive server tasks.

Configuration

Configure multiple servers together.

Deployment

Deploy applications automatically.

Ansible Playbook

---

- name: Install Nginx

  hosts: all

  become: yes

  tasks:

   - name: Install package

     apt:

      name: nginx

      state: present
Playbooks are written using YAML syntax.

Ansible Modules

Module Purpose

copy Copy files
service Manage services
ping Check connectivity
