What is Ansible?

Ansible is an open-source automation and configuration management tool used to automate repetitive tasks like package installation, application deployment, infrastructure provisioning and server configuration.

Automation

Automates repetitive infrastructure tasks.

Configuration

Manage multiple servers together.

Deployment

Deploy applications automatically.

Ansible Architecture

Control Node
     ↓
Inventory
     ↓
Playbook
     ↓
Modules
     ↓
Managed Nodes
Control Node: Machine where Ansible is installed.

Managed Nodes: Target servers controlled using SSH.

Playbooks

Playbook YAML

---
- name: Deploy HTML file
  hosts: webservers

  tasks:

    - name: Create HTML file
      copy:

        content: |
          <html>
          <body>
          <h1>Hello Nandy</h1>
          </body>
          </html>

        dest: /tmp/index.html

Command

ansible-playbook -i inventory deploy.yml

Output

PLAY RECAP

server1 : ok=2 changed=1
server2 : ok=2 changed=1
server3 : ok=2 changed=1

Variables Demo

---
- name: Variables Demo
  hosts: webservers

  vars:
    username: Nandy
    course: Ansible

  tasks:

    - name: Print variables
      debug:
        msg: "User is {{ username }} and course is {{ course }}"
Variables avoid hardcoding values and make automation reusable.

Loops Demo

---
- name: Loop Demo
  hosts: webservers

  tasks:

    - name: Create multiple files
      file:
        path: "/tmp/{{ item }}"
        state: touch

      loop:
        - file1.txt
        - file2.txt
        - file3.txt

Output

changed: [server1] => (item=file1.txt)
changed: [server1] => (item=file2.txt)
changed: [server1] => (item=file3.txt)

Conditions & Handlers

Conditions

when: inventory_hostname == "server1"

Handlers

notify: Restart Service

handlers:
 - name: Restart Service
   command: echo "Service Restarted"

Handler Flow

Vault Security

Command

ansible-vault create secrets.yml

Vault File

db_user: admin
db_password: secret120

Playbook

---
- name: Vault Demo
  hosts: webservers

  vars_files:
    - secrets.yml

  tasks:

    - name: Display username
      debug:
        msg: "User is {{ db_user }}"
