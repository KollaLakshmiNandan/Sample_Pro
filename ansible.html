1. What is Ansible?

Ansible is an open-source automation tool used for:

  • Configuration Management
  • Application Deployment
  • Infrastructure Automation
  • Server Provisioning
  • CI/CD Automation

Problem Before Ansible

Imagine company has 100 servers. Manually: Login server 1 Install nginx Configure Repeat 100 times Time consuming + Human Errors


Solution

Ansible automates everything from one machine.

6. YAML

YAML means: YAML Ain't Markup Language Used for playbooks.


name: nginx

Rules

  • Indentation important
  • No tabs
  • Use spaces

7. Playbooks

Playbook = Automation Script


---

- name: Install Nginx

  hosts: node

  become: yes

  tasks:

   - name: install nginx

     apt:

      name: nginx

      state: present

Explanation

  • hosts → target machine
  • become → sudo/root access
  • tasks → work to perform
  • apt → package module
