DevOps Concepts

1. What is DevOps?

DevOps is a combination of Development (Dev) and Operations (Ops). It helps teams automate software development and deployment processes for faster delivery and better collaboration.

2. DevOps Lifecycle

  1. Plan
  2. Develop
  3. Build
  4. Test
  5. Release
  6. Deploy
  7. Operate
  8. Monitor

3. Linux for DevOps

  • pwd - Present Working Directory
  • ls - List files
  • cd - Change Directory
  • mkdir - Create folder
  • touch - Create file

4. Git & GitHub

  • git init → Initialize repository
  • git add . → Add files
  • git commit -m "message" → Save changes
  • git push → Push to GitHub
  • git pull → Get latest changes

5. CI/CD

CI/CD stands for Continuous Integration and Continuous Deployment.

Continuous Integration (CI)

Developers merge code frequently and automated testing happens.

Continuous Deployment (CD)

Code is automatically deployed to servers after testing.

6. Docker

Docker is a containerization platform used to package applications and dependencies together.

7. Kubernetes

Kubernetes is used to manage, scale and deploy containers automatically.

8. AWS Services

Service Purpose
EC2 Virtual Server
S3 Storage Service
VPC Private Network
RDS Database Service

9. Infrastructure as Code

Infrastructure as Code (IaC) means managing infrastructure using code. Example tools: Terraform and Ansible.

10. Monitoring Tools

  • Prometheus
  • Grafana
  • Nagios
