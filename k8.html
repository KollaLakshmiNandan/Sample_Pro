1. Introduction to Kubernetes

Kubernetes (K8s) is an open-source container orchestration platform used to automate deployment, scaling, and management of containerized applications.

Why Kubernetes?

  • Automatic scaling
  • Self-healing applications
  • Rolling updates
  • Load balancing
  • Container orchestration
Fact: Most cloud-native applications today run on Kubernetes.

2. Kubernetes Architecture

4. Pods

Pod is the smallest deployable unit in Kubernetes. 

apiVersion: v1
kind: Pod
metadata:
  name: nginx-pod

spec:
  containers:
  - name: nginx
    image: nginx

5. Deployments

Deployments manage replicas and rolling updates. 

kubectl apply -f deployment.yaml

kubectl scale deployment nginx --replicas=5

kubectl rollout restart deployment nginx
