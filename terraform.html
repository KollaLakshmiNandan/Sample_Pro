What is Terraform?

Terraform is an Infrastructure as Code (IaC) tool used to create and manage cloud infrastructure using configuration files. 

resource "aws_instance" "web_server" {

  ami           = "ami-123456"

  instance_type = "t2.micro"

}

Terraform creates cloud resources automatically instead of manually creating them in AWS or Azure.

Terraform supports AWS, Azure, Google Cloud, Kubernetes, Docker, and many more platforms.

Why Terraform is Used

Cloud Automation

Automate infrastructure creation.

Consistency

Same infrastructure across environments.

Version Control

Track infrastructure changes easily.

Terraform Providers

Provider Purpose
AWS Manage AWS Infrastructure
Azure Manage Azure Resources
Google Cloud Manage GCP Infrastructure
Kubernetes Manage Kubernetes Clusters

Main Terraform Commands

terraform init

Initializes Terraform project.

terraform validate

Validates Terraform configuration.

terraform plan

Shows planned changes.

terraform apply

Creates infrastructure resources.

terraform destroy

Deletes infrastructure resources.

terraform fmt

Formats Terraform code.

Variables in Terraform

variable "region" {

  default = "us-east-1"

}

variable "instance_type" {

  default = "t2.micro"

}

Variables help avoid hardcoding values.

Terraform Output Example

output "instance_id" {

  value = aws_instance.web.id

}

Outputs display useful information after infrastructure is created.

Terraform State File

terraform.tfstate

Terraform uses the state file to track infrastructure resources.

In real DevOps projects, state files are stored remotely using S3 or Terraform Cloud.
