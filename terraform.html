1. What is Terraform?

Terraform is an Infrastructure as Code (IaC) tool developed by HashiCorp. It is used to automate infrastructure provisioning and management.

Why Terraform?

  • Automates cloud infrastructure
  • Supports AWS, Azure, GCP, Kubernetes
  • Version control infrastructure
  • Reusable infrastructure
  • Reduces manual work

Infrastructure as Code (IaC)

IaC means managing infrastructure using code instead of manual UI operations.

Example:
Instead of manually creating EC2 instances from AWS Console, Terraform creates them automatically using code.

2. Terraform Architecture

Main Components

Component Description
Terraform Core Main engine that reads configuration
Provider Connects Terraform to AWS/Azure/GCP
State File Tracks infrastructure changes
Resource Infrastructure objects like EC2, VPC
Module Reusable Terraform code blocks

Terraform Workflow

Write Code --> terraform init --> terraform plan --> terraform apply --> Infrastructure Created

Detailed Architecture Flow

User Writes Terraform Code (.tf files) ↓ Terraform Core Reads Code ↓ Provider Plugin Communicates with Cloud APIs ↓ Infrastructure Created in AWS/Azure/GCP ↓ Terraform State File Updated

3. Terraform Installation

Windows Installation

5. Terraform Practical Example

Create EC2 Instance

provider "aws" {
  region = "us-east-1"
}

resource "aws_instance" "myserver" {
  ami           = "ami-0c55b159cbfafe1f0"
  instance_type = "t2.micro"

  tags = {
    Name = "TerraformServer"
  }
}

Execution Steps

terraform init
terraform plan
terraform apply

Destroy Infrastructure

terraform destroy

6. AWS Real-Time Infrastructure Example

Create VPC + Subnet + EC2

provider "aws" {
  region = "us-east-1"
}

resource "aws_vpc" "main" {
  cidr_block = "10.0.0.0/16"
}

resource "aws_subnet" "subnet1" {
  vpc_id     = aws_vpc.main.id
  cidr_block = "10.0.1.0/24"
}

resource "aws_instance" "web" {
  ami           = "ami-0c55b159cbfafe1f0"
  instance_type = "t2.micro"
  subnet_id     = aws_subnet.subnet1.id
}

Dependency Management

Terraform automatically understands dependencies between resources.

VPC → Subnet → EC2 Instance

8. Terraform State File

What is terraform.tfstate?

Terraform stores infrastructure details in a state file.

Why State File Important?

  • Tracks infrastructure
  • Maps resources
  • Detects changes

Remote Backend

terraform {
  backend "s3" {
    bucket = "terraform-state-bucket"
    key    = "terraform.tfstate"
    region = "us-east-1"
  }
}

State Locking

DynamoDB is used for state locking to avoid concurrent modifications.

12. Terraform with CI/CD

CI/CD Flow

Developer Pushes Code → GitHub → Jenkins/GitHub Actions → Terraform Apply → AWS Infrastructure

GitHub Actions Example

name: Terraform

on:
  push:
    branches:
      - main

jobs:
  terraform:
    runs-on: ubuntu-latest

    steps:
      - name: Checkout
        uses: actions/checkout@v2

      - name: Setup Terraform
        uses: hashicorp/setup-terraform@v1

      - name: Terraform Init
        run: terraform init

      - name: Terraform Apply
        run: terraform apply -auto-approve

14. Terraform Advanced Concepts

Count

for_each

  for_each = toset(["dev", "test", "prod"])

  bucket = each.key

Dynamic Blocks

dynamic "ingress" {
  for_each = var.ports

  content {
    from_port = ingress.value

  }
}

17. Troubleshooting Scenarios

Issue: State Lock Error

Error acquiring the state lock

Solution

terraform force-unlock LOCK_ID

Issue: Resource Already Exists

Import existing resource into Terraform state. 

terraform import aws_instance.web i-123456
