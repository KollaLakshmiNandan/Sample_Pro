What is Terraform?

Terraform is an Infrastructure as Code (IaC) tool developed by HashiCorp.

It helps automate infrastructure creation using code instead of manual cloud setup. 

resource "aws_instance" "web" {

  ami = "ami-123456"

  instance_type = "t2.micro"

}
Terraform supports AWS, Azure, GCP, Kubernetes, Docker, and many more technologies.
