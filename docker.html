Docker Overview

Industry Problem Before Docker

Before Docker, applications worked differently across environments. Developers often faced: "Works on my machine but not in production" problems.

How Docker Solves This

Docker packages:

  • Application
  • Dependencies
  • Runtime
  • Libraries

inside lightweight containers.

What is a Container?

A container is an isolated lightweight environment that runs applications consistently across systems.

Difference Between VM and Container

Virtual Machine (VM)

  • Includes full operating system
  • Uses hypervisor
  • Larger resource usage

Container

Containers share the host OS kernel and remain lightweight.

Docker Images

Docker images are read-only templates used to create containers.

Docker Containers

Containers are running instances of Docker images.

Dockerfile

Dockerfile defines instructions for building Docker images.

Example Dockerfile

FROM python:3.9
COPY . .
RUN pip install -r requirements.txt
CMD ["python","app.py"]

Explanation

  • Uses Python base image
  • Copies application files
  • Installs dependencies
  • Starts application

Important Commands

docker build
docker run
docker ps
docker images
docker logs
docker stop
docker rm

Command Explanation

  • docker build - Builds Docker image
  • docker run - Starts container from image
  • docker ps - Displays running containers
  • docker logs - Displays logs for troubleshooting
  • docker images - Displays local Docker images

Docker Networking

Docker networking enables communication between containers.

Volumes

Volumes persist data outside containers.

Docker Compose

Docker Compose manages multi-container applications.

Docker Compose Example

services:
  web:
    image: nginx
